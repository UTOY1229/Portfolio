# John Leland Miñon — Portfolio

Static portfolio site. Open `index.html` locally, or publish the site files to a static host.

## Asset folders

- `assets/profile/` — profile and cutout photos
- `assets/projects/` — project and portfolio artwork
- `assets/events/` — event galleries, grouped by event
- `assets/videos/covers/` — AVP tape cover artwork
- `assets/resume/` — CV PDF and preview image
- `_archive/` — unused source material and local AVP originals, excluded from Git by `.gitignore`

The AVP player embeds the four videos from YouTube. Keep the videos public or unlisted with embedding enabled for playback in the portfolio.
