# John Leland Miñon — Portfolio

**Live site:** [utoy1229.github.io/Portfolio](https://utoy1229.github.io/Portfolio/)

Welcome! This is the portfolio of John Leland G. Miñon, a Computer Science student specializing in Software Engineering at FEU Institute of Technology. It brings together project work, event operations, creative media, skills, and ways to get in touch.

## What’s inside

- **Projects:** WAILS, HexLapTer, and my personal portfolio project
- **Experience & events:** Project management, SAGE logistics, and event work
- **Creative work:** Selected audio-visual presentations and video editing experience
- **Toolkit & learning:** Skills, certifications, and ongoing learning
- **Resume & contact:** CV preview, download, and contact links

## Built with

This is a static website built with HTML, CSS, and JavaScript. It does not require a package install or build step.

To view it locally, download or clone this repository and open `index.html` in a browser.

## Publishing

GitHub Pages serves the site from the `main` branch at the repository root. New commits pushed to `main` trigger a Pages deployment. The latest deployment can be viewed in the [Actions tab](https://github.com/UTOY1229/Portfolio/actions).

## Assets

- `assets/profile/` — profile photos and cutouts
- `assets/projects/` — project and portfolio images
- `assets/events/` — event gallery images, grouped by event
- `assets/videos/covers/` — artwork for the AVP player
- `assets/resume/` — CV file and preview image

The four AVP videos are embedded from YouTube. Playback depends on each video remaining available and allowing embeds.
